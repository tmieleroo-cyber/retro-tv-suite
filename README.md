# Retro TV Suite

Create a Smart TV retro gaming frontend with a dark interface, 10-foot UI navigation, NES/SNES/Game Boy/GBA categories, game library with cover art and metadata, and Wi-Fi controller pairing screen. All UI, copy, and documentation in Spanish with clean, well-structured code.
